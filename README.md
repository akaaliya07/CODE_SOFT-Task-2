# CODE_SOFT-Task-2
An unbeatable Tic-Tac-Toe AI built with Python and Tkinter, developed as part of the CodSoft Artificial Intelligence Internship (Task 2). The AI agent uses the Minimax algorithm enhanced with Alpha-Beta Pruning to calculate the optimal move for every board state.  

 Features
 Unbeatable AI Agent: Uses recursive game theory search to guarantee at least a draw against optimal human play.  
 Alpha-Beta Pruning: Optimizes the search tree depth to significantly reduce computation time.  
 Interactive GUI: Built with Python's built-in tkinter library for a smooth user experience. 
 Dynamic Turn Handling: Visual feedback showing game states, current turn, win conditions, and board resets.
